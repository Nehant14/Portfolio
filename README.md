# Personal Portfolio

This repository contains my personal developer portfolio, built with React and Vite featuring Hot Module Replacement (HMR) and ESLint rules.

## Vite Configuration

Official React plugins used with Vite:
- `@vitejs/plugin-react` (uses Oxc/Babel)
- `@vitejs/plugin-react-swc` (uses SWC)

## Expanding the ESLint Configuration

Standard React linting rules are enabled. For production code quality, TypeScript and `typescript-eslint` can be integrated for type-aware linting.
